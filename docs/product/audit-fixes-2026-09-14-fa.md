# نتیجه اصلاحات بررسی محصول — ۱۴ سپتامبر ۲۰۲۶

این سند پیگیری `audit-2026-09-14-fa.md` است. پرداخت با تصمیم صریح کاربر در این مرحله شبیه‌سازی‌شده باقی می‌ماند. تغییرات در محیط محلی اعمال شده‌اند و این سند گواه استقرار روی سرویس زنده نیست.

## اصلاحات

| مورد گزارش | نتیجه پیاده‌سازی |
| --- | --- |
| انتقال شاگرد | انتخاب کنترل‌شده مقصد، نمایش شرایط قبل از تأیید، انصراف با بازنشانی انتخاب، جلوگیری از ثبت تکراری و حفظ انتخاب در خطا. پرداخت‌های دستی و سهمیه مصرف‌شده به قرارداد مقصد منتقل می‌شوند؛ اختلاف مبلغ به بدهی یا بستانکاری تبدیل می‌شود. تخفیف به اعتبار نقدی تبدیل نمی‌شود. |
| انتقال ثبت‌نام آنلاین | مسیر صریح لغو و بازپرداخت با تأیید در پنل کلاس اضافه شد. پس از لغو، ثبت‌نام مقصد جداگانه انجام می‌شود؛ ظرفیت مقصد از پیش تضمین یا رزرو نمی‌شود. بازپرداخت از همان Commerce شبیه‌سازی‌شده انجام می‌شود. |
| دسترسی نظرهای باشگاه | خواندن نظرها از API مجاز پنل و بر اساس دسترسی `club.read` انجام می‌شود، مستقل از عمومی یا تعلیق بودن باشگاه. خطای شبکه با حالت بدون نظر اشتباه گرفته نمی‌شود و تلاش مجدد دارد. |
| سقف ۱۰۰ نظر | صفحه‌بندی، جستجوی متن، امتیاز و وضعیت پاسخ در سرور؛ شمارش کل و توزیع امتیاز مستقل از صفحه. پنل و صفحه عمومی باشگاه به صفحه‌های بعدی دسترسی دارند. بعد از پاسخ، صفحه اول باز می‌شود تا فیلتر «بی‌پاسخ» روی صفحه خالی گیر نکند. |
| برنامه امروز | جلسات واقعی دوره مربی و کلاس باشگاهیِ ثبت‌نام‌شده به برنامه ورزشکار اضافه شد. ثبت‌نام نامعتبر، جلسه لغوشده و زمان گذشته حذف می‌شوند؛ تغییر زمان از جلسات خوانده می‌شود. لینک به جزئیات متعلق به ورزشکار می‌رود. خطای بخشی از منابع، برنامه سایر منابع را پنهان نمی‌کند. |
| وعده معرفی | وعده امتیاز هوشمندِ پیاده‌نشده با توضیح قابلیت واقعی برنامه و ثبت تمرین جایگزین شد. |
| برند و دسترس‌پذیری | نام نمایشی فارسی و انگلیسی هماهنگ شد. نام قابل‌دسترس دکمه نهایی «شروع» است؛ اسلایدهای غیرفعال از تعامل و درخت دسترس‌پذیری خارج‌اند. دامنه‌ها و شناسه‌های فنی نصب موجود تغییر نکرده‌اند. |
| فرم‌های prompt | فرم مشترک چندخطی با اعتبارسنجی، وضعیت ارسال و نگهداری پیش‌نویس در خطا جایگزین promptهای پاسخ نظر، رد/تعلیق در ادمین، دسته مقاله و تغییر زمان مربی شد. |
| فاصله مربی | نقطه عمومی محل ارائه خدمت در پروفایل مربی با نقشه/مختصات قابل ثبت و حذف است. جستجوی شعاع و شمارش نتایج بر اساس مختصات واقعی انجام می‌شود. مربی بدون نقطه همچنان در جستجوی عادی دیده می‌شود. |
| بودجه و مقایسه | فیلتر بودجه علاوه بر کلاس‌ها، روی سانس قابل‌رزرو باشگاه و خدمت منتشرشده مربی اعمال می‌شود. گزینه مطابق بودجه با مبلغ و واحد جلسه/بسته/ماه نمایش داده می‌شود. برای بسته با تعداد جلسات معلوم، هزینه تقریبی هر جلسه نیز نمایش داده می‌شود. برای سهمیه نامشخص یا نامحدود عدد ساختگی محاسبه نمی‌شود. فیلتر بودجه همچنان بر مبلغ کامل اعلام‌شده قرارداد است. |
| کیفیت فنی | خطاهای lint، قالب‌بندی و چند الگوی ناسازگار React اصلاح شد؛ فایل‌های تولیدی Next از lint کنار گذاشته شدند. تنظیمات telemetry تست از محیط توسعه جدا شد. دیتابیس‌های موقت تست حافظه و oplog محدود دارند. |
| خطای یافت‌شده در تست کامل | رقابت ثبت هم‌زمان اولین آدرس‌ها اصلاح شد: انتخاب خودکار آدرس پیش‌فرض، برنده هم‌زمان دیگری را پاک نمی‌کند؛ سقف پنج آدرس و یکتایی پیش‌فرض در دیتابیس حفظ می‌شوند. |

## اعتبارسنجی

- `npm run lint`: هر ۹ task موفق.
- `npm run check-types`: هر ۹ task موفق.
- `npm test --workspace backend -- --runInBand`: هر ۴۳۳ تست در ۹۴ مجموعه موفق.
- `npm run test:offline -w application`: هر ۲۵ تست موفق.
- خروجی خام بررسی‌ها در `test-results/audit-final/` نگهداری شده است؛ این پوشه خروجی تولیدی است و وارد Git نمی‌شود.

- `npm run build:cap -w application`: خروجی وب بومی با موفقیت ساخته شد. هشدار اندازه chunk نقشه همچنان وجود دارد؛ این فرمان ساخت/نصب APK و تست دستگاه نیست.
- `npx playwright test -c playwright.audit.config.ts` در اپ: هر ۷ تست موفق.
- `npx playwright test -c playwright.audit.config.ts` در پنل باشگاه: هر ۲ تست موفق (نظرها و انتقال/بازپرداخت).

تست‌های جدید شامل این سناریوها هستند:

- دریافت صفحه ششم از ۱۰۵ نظر، جستجوی متن و کنترل دسترسی باشگاه غیرعمومی.
- فاصله واقعی و بودجه مربی، همراه مبلغ و واحد گزینه مطابق فیلتر.
- انتقال قرارداد به شهریه بیشتر و کمتر با حفظ رسیدها و جلسات مصرف‌شده.
- جلسه ثبت‌نام‌شده، تغییر زمان، لغو و جداسازی ورزشکارها در agenda.
- معرفی، نام دکمه نهایی و دسترس‌پذیری اسلایدها.
- شکست یک منبع agenda و تلاش مجدد؛ اندازه موبایل و دو تم.
- نظرهای پنل، خطای شبکه، صفحه‌بندی و حفظ پیش‌نویس پاسخ.
- انتخاب/انصراف/شکست/تلاش مجدد انتقال شاگرد و تأیید صریح لغو آنلاین.

## مرز تأیید

- اتصال، استرداد و تسویه بانکی واقعی در دامنه فعلی نیستند؛ پرداخت عمداً شبیه‌سازی‌شده است.
- تست دستگاه فیزیکی، Push در حالت بسته، نصب/به‌روزرسانی APK روی دستگاه، تنظیمات تولید و بازیابی backup زنده در این محیط انجام نشده‌اند. تأیید انتشار روی دستگاه و زیرساخت واقعی همچنان لازم است.
- تغییرات روی محیط زنده منتشر نشده‌اند.
