# بازطراحی مرجع تصویری برای Club4Me

تاریخ: ۲۰۲۶-۰۹-۰۹

این خروجی پیشنهاد طراحی است؛ پیاده‌سازی یا تأیید عملکرد زنده اپ نیست. تصویر ارسالی مرجع بصری محسوب شده و متن‌های داخل آن دستور اجرایی نیستند. نام‌ها، تصاویر اشخاص، قیمت‌ها و امتیازهای طرح داده نمونه‌اند.

## مبنای تطبیق با اپ

- زبان فارسی، راست‌به‌چپ و خانواده فونت IRANSansX مطابق `packages/theme/src/heroui.css`.
- سبز فعلی برند با توکن `--accent` حفظ شود؛ زرد لیمویی مرجع به‌عنوان رنگ جدید برند وارد نشود.
- استفاده از الگوهای موجود Sandow: فاصله بیرونی ۱۶، فاصله کارت‌ها ۱۲، گوشه کارت ۲۴ تا ۳۲ و دکمه اصلی ۵۶ پیکسل. کنترل‌های مشترک فعلی ممکن است ارتفاع ۶۴ داشته باشند؛ تغییر سراسری لازم نیست.
- اپ علاوه بر کشف و رزرو، مسیرهای برنامه تمرینی، ثبت پیشرفت و عضویت دارد؛ طرح باید دسترسی به آن‌ها را نشان دهد.
- مبالغ با واحد صریح تومان، تاریخ شمسی و ساعت محلی نمایش داده شوند. تبدیل واحد پول باید مطابق قرارداد API باشد.
- طرح تصویری روی مسیر ورزشکار تمرکز دارد؛ پنل مربی و کسب‌وکار به جریان مستقل نیاز دارند.

## آنچه از تصویر می‌توان استفاده کرد

| الگوی مرجع | استفاده در Club4Me | اصلاح پیشنهادی |
| --- | --- | --- |
| زمینه تیره و یک رنگ تأکیدی | توکن‌های معنایی تم فعلی | سبز برای اقدام اصلی و انتخاب فعال؛ وضعیت‌ها همراه متن و آیکون |
| کارت باشگاه | کشف و پیشنهادها | تصویر، نام، محله، امتیاز با تعداد نظر و قیمت واقعی؛ فاصله فقط با مکان معتبر |
| کارت مربی | فهرست و جزئیات مربی | تخصص، خدمت قابل رزرو و زمان آزاد؛ مدارک فقط در صورت وجود داده معتبر |
| چیپ‌های فیلتر | باشگاه، مربی، کلاس و ورزش | حالت انتخاب روشن، تعداد نتیجه و امکان پاک‌کردن فیلتر |
| نوار تاریخ و شبکه ساعت | انتخاب جلسه | تقویم شمسی، روز غیرفعال و ساعت پر؛ تفکیک با متن و شکل، نه فقط رنگ |
| خلاصه رزرو | صفحه مرور قبل از پرداخت | تاریخ، محل، خدمت، تعداد نفرات، پوشش عضویت و مبلغ نهایی |
| تأیید رزرو | نتیجه عملیات | تمایز رزرو تأییدشده، در انتظار پرداخت و ناموفق؛ موفقیت بر اساس پاسخ سرور |
| تب رزروهای آینده و گذشته | رزروهای ورزشکار | افزودن وضعیت پرداخت و اقدام مرتبط؛ تغییر زمان و لغو تابع قوانین همان رزرو |
| ردیف‌های پروفایل و تنظیمات | مؤلفه‌های مشترک موجود | نمایش عضویت، تمرین، اعلان و پشتیبانی؛ حفظ تنظیمات تم و نقش‌ها |
| نقشه مسیر صفحات | مستند جریان محصول | اتصال به مسیرهای فعلی و افزودن تمرین، عضویت و حالت‌های خطا |

از یک PNG می‌توان ساختار، سلسله‌مراتب، ترکیب رنگ تقریبی و الگوهای تعامل را استخراج کرد. لایه‌های قابل ویرایش، کامپوننت Figma، فونت دقیق، آیکون اصلی و عکس باکیفیت مستقل از آن به دست نمی‌آید. برای محصول از لوگو، فونت، آیکون و عکس‌های موجود اپ استفاده شود؛ برش عکس‌های ریز این برد برای انتشار مناسب نیست.

## هشت صفحه منتخب برد جدید

خانه، کشف، جزئیات باشگاه، مربی، انتخاب زمان، تأیید و پرداخت، رزروها و برنامه تمرینی. انتخاب این صفحات برای خوانایی برد و نمایش مسیر اصلی است؛ صفحات دیگر در جدول بالا پوشش داده شده‌اند.

خانه باید در دو حالت طراحی شود: با رزرو، کارت جلسه بعدی مهم‌ترین بخش است؛ بدون رزرو، جست‌وجو و اقدام «پیدا کردن اولین جلسه» جای آن را می‌گیرد. دسترسی تمرین از خانه باقی می‌ماند. نوار چهارمقصدی در برد یک پیشنهاد معماری است و باید پیش از پیاده‌سازی با ناوبری فعلی تطبیق داده شود.

## چیزهایی که نباید عیناً منتقل شوند

- فرم کارت بانکی داخل اپ، قیمت IRR و تاریخ میلادی مرجع.
- فونت بسیار ریز، تراکم ۱۹ گوشی و کنتراست پایین توضیحات.
- امتیاز، فاصله، تخفیف، مدرک مربی یا امکان پرداخت حضوری بدون داده و پشتیبانی واقعی.
- ادغام «برنامه تمرینی» و «رزروهای من» زیر یک عنوان مبهم.
- محدودکردن محصول به فهرست باشگاه و مربی و حذف عضویت‌ها، کلاس‌ها و تمرین.

## اولویت اجرای پیشنهادی

۱. خانه و کشف: جلسه بعدی، جست‌وجوی واضح و کارت‌های یکدست.

۲. جزئیات و رزرو: اقدام ثابت پایین صفحه، ساعت‌های قابل انتخاب و خلاصه مبلغ.

۳. رزروها و تمرین: وضعیت روشن، ادامه پرداخت، اقدام‌های مجاز و دسترسی به برنامه امروز.

۴. تکمیل حالت‌های خالی، بارگذاری، خطا، مجوز موقعیت ردشده و پرشدن سانس حین رزرو؛ سپس بررسی تم روشن، RTL، اندازه متن و ناحیه امن گوشی.
